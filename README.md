# NSF Resilient CBCPS Project Website

This is a static GitHub Pages website for the NSF project **“Research Initiation Award: Integrating AI for Resilient Cloud-Based Cyber-Physical Systems.”** The award period is September 1, 2026, through August 31, 2029.

## Publish on GitHub Pages

1. Sign in to GitHub and create a new **public** repository, such as `nsf-resilient-cbcps`.
2. Upload all files and the `assets` folder from this package to the repository root.
3. Open the repository’s **Settings**.
4. Select **Pages** from the left menu.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose the `main` branch and the `/ (root)` folder, then click **Save**.
7. GitHub will display the website address after deployment completes.

## Update the website

- Edit project text in `index.html`.
- Add photographs to the `assets` folder and update their file paths in `index.html`.
- Edit colors and layout in `styles.css`.
- The clickable tab behavior is in `script.js`.

No installation or build command is required.
